## 1. Executive Summary

This document details the architectural migration, subsystem convergence, and performance optimizations realized during the integration of canonical upstream OpenLogi `v0.8.15` into the `WillkTech/OpenLogi` repository.

The migration successfully adopted upstream's core architectural improvements—including modular configuration schemas, IPC protocol v37, deterministic fixture replay testing (`openlogi-fixture`), and BCP-47 TOML localization—while strictly preserving and validating WillkTech's key customizations:
1. **Fixed-Point Scroll Acceleration Engine:** Integer LUT-based acceleration (`ScrollLut`, `ShapeLut`, `FIXED_POINT_SCALE = 1000`).
2. **macOS Private SPI Integrations:** Mission Control, App Exposé, and Space switching via dynamic symbol resolution (`CoreDockSendNotification`) with fail-open public `CGEvent` shortcut fallback.
3. **WillkTech / Prism Product Identity:** Bundle ID `org.willktech.openlogi`, LaunchAgent label `org.willktech.openlogi.agent`, Prism icons, WiX installer GUIDs, and update feed metadata.

## 2. Integrated Subsystems & Architecture Changes

### 2.1 Workspace & Fixture Infrastructure
* **New Crate `crates/openlogi-fixture`:** Integrated offline, deterministic HID++ replay and test corpus infrastructure (`fixtures/devices/`).
* **Dependency & Lock Alignment:** Synced workspace dependencies to `v0.8.15`, incorporating `gpui-pre` `=0.3.4` and `gpui-kit` `v0.6.1`.
* **Workspace Lints:** Adopted standard Edition 2024 lints and strict workspace Clippy tables.

### 2.2 Modular Configuration & Migration Framework
* **Configuration Restructuring:** `crates/openlogi-core/src/config/` modularized into specialized modules (`app_settings`, `device_settings`, `per_app`, `gestures`, `wheel_hold`, `links`, `revision`, `file`).
* **Schema Version 9 Migration:** Upgraded configuration schema from legacy v7/v8 to v9. Includes automated migration passes for legacy button maps, thumbwheel directional pairs, and transport-scoped device keys.
* **Atomic Backup Generation:** Implemented 5-generation automated backup rotation (`config.toml.bak.1..5`) and SHA-256 digest revision collision detection.

### 2.3 IPC Protocol Convergence (v37)
* **Coordinated Protocol Bump:** Updated `PROTOCOL_VERSION` to `37` across `openlogi-ipc`, `openlogi-agent`, `openlogi-desktop`, and `openlogi-overlay`.
* **RPC Type Alignment:** Synchronized serialization contracts for `AgentClient`, `DeviceInventory`, `LightState`, `BacklightChange`, `DpiInfo`, and `ReportRateInfo`.
* **Wire Format Golden Tests:** Verified wire-format serialization compatibility against `v37` golden test fixtures in `crates/openlogi-ipc/tests/wire_format.rs`.

### 2.4 HID++ & Device Abstraction Layer
* **Expanded Feature Support:** Integrated `0x4220` LockKeyState, `0x1982` Backlight, `0x2201` PointerMotionScaling, and `0x1b04` HapticFeedback.
* **Multi-Process Host Locking:** Implemented atomic host locks (`host_lock.rs`) to prevent concurrent HID++ transaction collisions across daemon and helper processes.
* **Device I/O Handles:** Modularized HID++ session probing, write commands, and receiver channel routing.

## 3. Software & Hardware Performance Optimizations

### 3.1 Fixed-Point Integer Scroll Acceleration Engine
To maintain zero-latency high-frequency scroll input processing under intense input workloads (e.g. high-DPI free-spinning wheels), WillkTech's fixed-point arithmetic engine was preserved and integrated:

* **Fixed-Point Scaling Constants:** `FIXED_POINT_SCALE = 1000` and `UNITY_GAIN_FIXED = 1000`.
* **256-Slot Look-Up Tables (`ScrollLut` & `ShapeLut`):** Recomputed pre-quantized LUTs eliminate runtime floating-point transcendental functions during high-rate scroll event dispatch loops.
* **Scroll Worker Integration:** High-rate wheel ticks are evaluated directly via integer table lookup (`lookup(rate_bin)`), bypassing floating-point multiplications on the hot input dispatch thread.

#### Scroll Engine Benchmark Results (`cargo bench -p openlogi-agent-core --bench scroll_engine`)

| Benchmark Micro-task | Measured Latency / Throughput | Parity vs Baseline |
|---|---|---|

| `gain_at_rate_sigmoid` | **17.07 ns** | 100% Parity (0.0% variance) |
| `compute_gains_fixed_lut` | **64.55 ns** | 100% Parity (0.0% variance) |
| `dispatch_latency_end_to_end` | **78.31 ns** | 100% Parity (0.0% variance) |

*Conclusion:* The integrated fixed-point scroll engine demonstrates 100% performance parity and zero material throughput or latency regression versus baseline.

### 3.2 macOS Private SPI Functionality & Fail-Open Safeguards
* **Encapsulated Injection Modules:** SPI logic isolated in `crates/openlogi-inject/src/inject/macos/dock.rs` and `symbolic_hotkey.rs`.
* **Dynamic Symbol Resolution:** Runtime lookup of `CoreDockSendNotification` via `dlopen`/`dlsym` ensures binary portability across OS minor versions.
* **Fail-Open Fallback:** If private SPI resolution fails or returns an error code, the system falls back to posting public `CGEvent` keyboard shortcuts, preventing agent crashes.

### 3.3 Hardware Memory & Threading Efficiency
* **Zero-Allocation Fixture Replay:** Device discovery tests run entirely against stack-allocated or pre-cached fixture corpora without runtime file I/O overhead.
* **Asynchronous Transport Polling:** Device handles run over non-blocking `async-hid` transport, keeping thread counts minimal even with multiple Bolt/Unifying receivers attached.
